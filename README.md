# yes-or-yes 💌

> **할 수 밖에 없는 데이트 신청** — 선택지는 YES 아니면… YES뿐이야.

데이트 신청을 거절하고 싶어도 할 수 없는 짓궂은 원페이지 웹사이트입니다.
NO 버튼은 잡히지 않고, 끝까지 버티면 타노스처럼 사라집니다. ✨

## 🎮 플레이 흐름

```
"우리… 데이트 할래?"  🥺
   │
   ├─ NO에 다가가면 → 슉슉 도망 (4번 도망치면 입자가 되어 소멸 💨)
   │    └─ 도망칠수록 멘트가 다급해지고, 이모지는 점점 서럽게 웁니다
   │
   ├─ NO가 살아있을 때 YES를 누르면 → "뭐야…? 안 튕겨도 되는 거야?" (밀당 모드)
   │    └─ 여기서 NO를 누르면 → 점점 애절해진 질문으로 다시 원점 🔁
   │
   └─ 결국 YES → 날짜/시간/장소 선택 → 💌 DATE TICKET 발급 → 카카오톡 공유
```

## ✨ 기능

- **도망다니는 NO 버튼** — 마우스/터치가 다가오면 화면 곳곳으로 순간이동 (카드와 YES 버튼은 피해서 착지)
- **소멸** — 4번째 도망에서 NO 버튼이 픽셀 입자로 흩어지며 소멸 (Canvas, 라이브러리 없음)
- **밀당 모드** — NO 소멸 전에 YES를 누르면 되묻기 → 거절하면 재신청 루프
- **단계별 감정 연출** — 거절당할수록 멘트는 애절해지고, 커스드 이모지는 더 서럽게 울고, 배경은 우중충해짐 (YES를 누르면 다시 화사하게 🌸)
- **효과음** — 뿅(도망) / 슈욱(소멸) / 뚜웅(거절) / 빰빠밤(수락) 전부 Web Audio로 합성 (오디오 파일 0개)
- **수신인 이름 개인화** — 링크 뒤에 이름을 붙이면 "희진아, 우리… 데이트 할래?"처럼 문구 전체에 이름이 반영 (받침 유무에 따라 아/야 자동 처리)
- **데이트 확정 티켓** — 날짜/시간/장소 선택 후 DATE TICKET 발급
- **카카오톡 공유** — 모바일 공유 시트(Web Share API) → 클립보드 복사 폴백. 카카오 앱키를 넣으면 카톡 직접 공유
- **모바일 대응** — visualViewport 기준 도망 범위, 작은 화면 레이아웃 최적화

## 🚀 실행

빌드도 설치도 없습니다. 그냥 열면 됩니다.

```bash
# 방법 1: 파일 직접 열기
index.html 더블클릭

# 방법 2: 로컬 서버 (선택)
python -m http.server 8000
# → http://localhost:8000
```

## 💌 수신인 이름 넣기

링크 뒤에 이름을 붙여서 보내면, 받는 사람 이름이 화면 곳곳에 자동으로 들어갑니다.

```
https://<username>.github.io/yes-or-yes/?name=희진   ← 쿼리 방식
https://<username>.github.io/yes-or-yes/#희진        ← 해시 방식 (더 짧음)
```

- 주소창에 한글을 그대로 적어도 됩니다 (브라우저가 자동으로 인코딩)
- 받침 유무에 따라 호칭이 자동으로 붙습니다 — 희진 → "희진**아**", 지수 → "지수**야**", 영어 이름은 그대로
- 이름이 반영되는 곳: 탭 제목, 첫 질문, 날짜 화면 인사, NO 소멸 멘트, 재신청 멘트
- 이름 없이 접속하면 "우리… 데이트 할래?" 같은 범용 문구로 표시됩니다
- 카카오톡 **링크 미리보기**(og 태그)는 크롤러가 JS를 실행하지 않아 이름이 들어가지 않습니다 (범용 문구로 표시)

## 🎨 커스터마이징

[index.html](index.html) 상단의 `CONFIG`만 바꾸면 됩니다.

```js
const CONFIG = {
  question:  "…",                    // 첫 화면 질문 (URL에 이름이 있으면 "OO아, " 자동 접두)
  fromName:  "",                     // 보내는 사람 이름 (공유 메시지에 포함)
  kakaoJsKey: "",                    // 카카오 JavaScript 키 → 넣으면 카톡 직접 공유 ON
  maxDodges: 4                       // NO가 몇 번 도망친 뒤 소멸할지
};
```

멘트도 전부 배열로 분리돼 있어 취향껏 수정할 수 있습니다.

| 배열 | 역할 |
|---|---|
| `TAUNTS` | 도망칠 때마다 나오는 도발 멘트 |
| `TEASE_TITLES` | 밀당 모드 되묻기 질문 (회차별) |
| `REJECT_SUBS` | 밀당에서 거절당했을 때 멘트 |
| `ASK_AGAIN_TITLES` | 거절 횟수별로 애절해지는 재신청 질문 |
| `TAUNT_IMGS` / `REJECT_IMGS` | 단계별 커스드 이모지 이미지 |

## 🛠 기술

- 순수 HTML / CSS / JavaScript **단일 파일** — 외부 라이브러리, 프레임워크, 빌드 도구 없음
- Canvas 픽셀 입자 애니메이션 (타노스 소멸)
- Web Audio API 효과음 합성
- Web Share API + Clipboard API (카카오톡 공유)
- `emojis/` — 배경 제거된 커스드 이모지 PNG (원본 JPG 포함)

4. 링크 뒤에 받는 사람 이름을 붙여서 보내면 끝 💘

```
https://<username>.github.io/yes-or-yes/?name=<수신인 이름>
```
